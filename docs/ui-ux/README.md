# Hệ thống Thiết kế UI/UX & Màn hình Figma

Thư mục này chứa thông tin hệ sinh thái giao diện người dùng trích xuất từ thiết kế Figma phiên bản 2.1.

---

## Danh mục tài liệu:
- [design-tokens.md](./design-tokens.md): Hệ thống màu sắc thương hiệu, Category Theming cho 3 bài thi (L&R Blue, Speaking Purple, Writing Green), Typography và Master Component states.
- [screens-inventory.md](./screens-inventory.md): Bảng tra cứu toàn diện 44 màn hình Figma theo Mã màn hình, Tên Figma Frame ID, URL Route và Quyền truy cập.
- [specs/figma-screens-master.md](../specs/figma-screens-master.md): Đặc tả chi tiết từng component và tương tác của toàn bộ 44 màn hình.
